Order to doorstep with no manual courier step

A WooCommerce order triggers an Instamojo payment whose webhook confirms the transaction; payment status is reconciled before fulfilment. A confirmed order auto-creates a Shiprocket shipment, generates the tracking ID and syncs shipping status back to the customer.

  • webhook payment confirm + reconcile
  • auto shipment + tracking ID
  • 2 years daily paid ads on ROAS
Technical deep dive

From offline resale to a store

Bootstrapped sneaker resale (Feb 2020 – Aug 2022) that outgrew manual operations: inventory visibility, inconsistent pricing and unpredictable repeat rates. I built a WooCommerce storefront with custom front-end workflows and inventory logic; managed hosting, deployment and SSL.

Payments (Instamojo)

  • Gateway integration with webhooks for order confirmation and transaction validation.
  • Payment-status reconciliation and refund logic; error handling for failed transactions.

Logistics (Shiprocket)

  • Shipment creation automated from order triggers; tracking IDs generated by the API.
  • Shipping status synced back to customers, replacing manual courier handling.

Measurement

  • Google Analytics plus SQL exports and Python analysis: acquisition channels, conversion, cart abandonment, repeat purchase, AOV, cohorts; funnel dashboards to find drop-offs.
  • A/B tests on pricing tiers and promotional creatives; paid Instagram, Facebook and Google Ads run daily for two years, testing creatives and audiences against ROAS.

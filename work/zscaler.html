what I actually did

  • The core problem: Salesforce formula fields recompute in real time but don't bump LastModifiedTimestamp, so incremental ingestion kept falling back to full refreshes — slower reports, more compute cost, less trust in the dashboards.
  • The fix was a compiler, not a prompt: pulled formula definitions via the ObjectDetails API, extracted complete formula logic, ran a depth-first traversal over nested field dependencies, and emitted structured JSON context (dependency graph + formula text) into an LLM that produced optimized SQL, inserted into version-controlled dbt models.
  • Because LLM-assisted generation adds risk, I engineered the verification: automated sampling that compared transformed warehouse output against the live CRM source, flagged discrepancies programmatically, and drove reconciliation dashboards — 100% validation confidence before deployment.
  • Redesigned ingestion around incremental upserts and change detection, with partitioning and clustering tuned for Snowflake on location-based attributes; heavy transforms stayed in the warehouse, off the request path.
  • Integrated LinkedIn Campaign, Asana and Jira APIs into the analytics pipeline with normalized schemas and dashboards; Git-based CI with automated schema checks and SQL tests via GitHub Actions and Docker.

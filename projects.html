The same rules in public code

Sentinel AI hackathon winner

Local Qwen3-VL on an HP ZGX Nano: video never leaves the site. The dispatch path needs human confirmation, has a kill switch, and fires once per incident.

Code on GitHub Watch demo
How dispatch is fenced

Team of five; owned the frame-streaming backend, asynchronous event routing, alert triggers and incident logging.

  • YOLO26s-pose plus temporal rules screen every frame; only score-escalated events send a 16-frame evidence bundle to Qwen3-VL-30B-A3B FP8.
  • Incident state machine (NEW → ALERTED → DISPATCH_PENDING → DISPATCHED) with SQLite history; at most one dispatch per incident.
  • Addresses come from a fixed camera-to-address map. Demo calls never reached the real 911 service.

Blast Radius

Three agents test an upstream schema change against downstream repos, each with least-privilege scope. The merge gate rejects approvals from non-owners.

Code on GitHub Watch demo
The owner gate

Team project; owned the impact coordinator and the owner-gated merge check. The coordinator holds the upstream required check pending until every downstream repo owner approves. In the demo, renaming user_id to account_id broke six checks, a non-owner's approval was rejected, and the check went green only after the real owners signed off.

Case Automation Agent

Triage, planning and execution as separate layers. One executor checks approval and permission before any tool call, for both the deterministic and the Claude planner.

Code on GitHub
The enforcement boundary

Naive-Bayes triage with confidence and out-of-scope escalation; a planner grounded in knowledge articles and logs; an append-only audit across lockouts, MFA, access requests, report timeouts and rate-limit cases. Because both planners sit behind the same executor, no provider can bypass the gates.

AI CodeGate

A merge gate: deterministic diff, lint and unit-test checks plus a severity-rated LLM reviewer. A change lands only if every hard check passes and no blocking finding remains; every decision is appended to a hash-chained audit log, so editing one breaks every hash after it.

Code on GitHub
The audit chain

Each log entry stores the decision (pass or reject), the severity of every finding and the hash of the previous entry. A tampered or deleted entry breaks the chain from that link on. The tested prototype uses a deterministic mock LLM provider.

Rx Fulfillment API

Telehealth orders that survive retries: idempotent payment and pharmacy webhooks, a transactional outbox, an audit log and field-level encryption on a tRPC + Drizzle order state machine.

Code on GitHub
Exactly-once side effects

The outbox row is written in the same transaction as the state change, so a retried webhook cannot emit a side effect twice, and the webhook handlers are idempotent. Designed for AWS Lambda, SST and RDS.

more from the lab, each linked to its repo

  • lakelog Delta/Iceberg-style transaction log in Java: optimistic writers commit through an atomic filesystem link so exactly one wins each version; snapshots, checkpoints every 10 versions, time travel.
  • pg-wal-lab PostgreSQL C extension for WAL and MVCC inspection plus a crash-recovery harness, built with PGXS against Postgres 14–16 in CI.
  • orderbook-engine C++20 price-time matching with O(1) cancel via an order-ID index: ~4.68M msgs/s, p99 ~900 ns on a 2M-message replay.
  • edge-llm-roofline Analytical prefill/decode model for LLMs on edge NPUs, within 8.7% MAPE of Jetson Orin and RTX 4090 measurements.
  • gpu attention lab RTX 5090: fused attention cut peak memory 16,648 → 264 MiB at 16k tokens and latency 46.81 → 27.07 ms.
  • spec-decode-lab distilgpt2 drafts k tokens, gpt2-medium verifies them in one batch; accept/reject with probability correction preserves the target distribution.
  • llm-shard-planner Enumerates tensor, expert and pipeline parallel plans for dense and MoE models, drops those over HBM, ranks by prefill latency and decode throughput.
  • dataflow-fusion-compiler torch.fx → typed SSA IR, producer-consumer fusion and SRAM-fitting placement on a PE grid; cycles are modeled, not measured silicon.
  • gpu-job-orchestrator Go scheduler over 512 GPUs in AWS, GCP and on-prem pools: gang scheduling, tenant quotas, rollback to the last checkpoint on spot preemption.
  • fleet-control-plane Go device control plane: versioned desired vs reported config shadows, conditional writes that reject stale versions, TTL heartbeats.
  • dedup-store C++20 FastCDC chunking with SHA-256 fingerprints and a journaled mark-and-sweep GC that resumes after a crash.
  • sensor-hub-firmware Host-simulated HAL with 1 kHz sensor reads into a lock-free ring buffer; no deployed MCU.

Zoox Perception · summer 2026

Teaching a fleet of data miners to grade their own work

At Zoox, ~409 perception data miners search drive logs for scenes that become labeled training data, and nobody could automatically say whether they were finding the right ones. As a Software Engineer Intern, Ayush built the loop that scores each miner against the human labels it already had: 321 of 321 eligible miners validated, with exact, reproducible numbers.

fig. 2 · what happens to every mined event, for every miner

  1. Miners search them for scenes worth labeling.

  2. 90M+ events a week: pedestrians, signs, reverse lights.

  3. The ground truth already existed. Nobody was grading miners with it.

  4. miner → task → view is deterministic. A wrong view fails silently, so no LLM here.

  5. Grounded in miner intent, ontology and the real label vocabulary. Run against live counts; bad SQL or odd counts go back for another draft. The LLM only writes the rule; scoring never calls it.

  6. Plain SQL over every labeled event, no sampling. Median ~1.3 s per miner.

  7. Weekly S3 snapshots, no backend. Failures surface in minutes, not days.

What he built

  • Automated ground-truth precision for the perception data-mining fleet: every miner scored against human labels its own events already had, at zero extra labeling cost.
  • A grounded LLM step that writes each miner's SQL true-positive predicate, then executes, verifies and retries it against live label counts before it is trusted.
  • Deterministic scoring over the full labeled population, no sampling, with the canonical SQL stored next to every number so anyone can rerun it.
  • A scheduled fleet-wide sweep: 321 of 321 GT-capable miners validated with no backlog, ~1.3 s median scoring per miner, and write-on-change history with ~93% fewer redundant writes.
  • Latest precision in the main miner table from one window-function query: no N+1, no warehouse calls on the request path.
  • Weekly S3 report snapshots behind a zero-backend TypeScript and Chart.js dashboard, Slack digests, owner DMs and event-driven failure alerts that cut failure discovery from days to minutes, plus a read-only, grounded Slack Q&A.
  • Ground-truth and VLM validation as two first-class methods, a fleet-wide label-coverage investigation, and all of it shipped as ~14 small, deployable PRs.

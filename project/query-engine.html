C++20 · analytical engine from scratch

Columnar query engine

A mini analytical engine with an explicit plan, optimizer passes and a vectorized executor over column files with min/max skipping — checked against a row-at-a-time reference on 4M rows.

the numbers

1,500randomized queries checked against a reference interpreter

2,048row vectorized batches with selection vectors

63 / 80row groups skipped by min/max on a one-year filter

how it works

  • Plan: explicit logical operators — Scan, Filter, Project, Aggregate, HashJoin, Limit.
  • Optimizer: constant folding, filter pushdown through projections and joins into scans, and unused-column pruning.
  • Execution: batch-at-a-time vectorized execution over column vectors with selection vectors.
  • Storage: row-group columnar files with dictionary encoding, footer metadata and per-column min/max stats so predicates skip row groups before deserialization.

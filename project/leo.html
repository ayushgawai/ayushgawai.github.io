LEO satellite coverage risk · 2026

A tool-use agent over 4.7 million locations

Scores tree and terrain obstruction risk for LEO satellite service at every North Carolina location. A Claude tool-use orchestrator sequences five deterministic Python tools and passes artifacts as file paths, so millions of rows never enter the context window. A pipeline-only mode runs the same functions with no LLM at all.

  • 4,674,905 locations scored
  • 100/100 counties
  • 250 tests

Technical deep dive

Data chain

  • Location coordinates and IDs; NLCD and USGS canopy rasters; USGS 3DEP elevation with derived slope; NLCD land-cover classes.
  • Spatial sampling at each location, component scoring into HIGH / MODERATE / LOW tiers using Starlink installation guidance, validation of coordinates and county coverage.

Agent design

  • Claude tool-use orchestrator over ingest_locations, sample_environment, score_risk, validate_results, generate_report. Python does the geospatial and numeric work; file-based state passes artifact paths, not rows, into the prompt.
  • Interactive tools answer coordinate, address, area, polygon and nearby-alternative questions over the precomputed scores; a web app serves map and search.
  • Pipeline-only mode runs the same functions with no LLM.

March 2026 run

  • All 4,674,905 locations scored, 100 of 100 counties, 0.0% environmental NaNs, tiers HIGH 19.4% / MODERATE 31.3% / LOW 49.3%, 250-test suite.

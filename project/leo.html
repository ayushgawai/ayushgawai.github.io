LEO satellite coverage-risk agent

Scores 4.67M candidate broadband-install sites for LEO-satellite obstruction risk — tree canopy and terrain, the gap between 'covered on the map' and 'works in practice' — with a Claude tool-use orchestrator over five deterministic tools.

how it works

  • Data chain: location coordinates and IDs join NLCD and USGS canopy rasters, USGS 3DEP elevation with derived slope, and NLCD land-cover classes; spatial sampling at each site feeds component scores into HIGH, MODERATE or LOW tiers using Starlink installation guidance.
  • Agent architecture: a Claude tool-use orchestrator decides the next step across five deterministic tools — ingest_locations, sample_environment, score_risk, validate_results, generate_report. Python does the geospatial and numeric work; file-based state passes artifact paths instead of millions of rows into the prompt.
  • Pipeline-only mode runs the same functions without an LLM; interactive tools analyze coordinates, addresses, areas, polygons and nearby alternatives over the precomputed scores.
  • Output: reports, charts and a scored CSV served through an interactive web app with a map and search.

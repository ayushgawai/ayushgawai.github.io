Parallel coding agents · Python + FastAPI

Agent fleet

A CLI and dashboard that gives each coding-agent task its own Git branch and worktree, shards tests across workers, and gates every diff through a review gate before a human approves.

how it works

  • Isolation: each task gets its own branch and worktree, running in a Docker or subprocess sandbox.
  • Verification: test suites are sharded across workers using historical-duration LPT scheduling, and JUnit results are merged.
  • Review gate: a diff-review gate checks for deleted tests, weak assertions, secrets, network calls and large changes, with optional LLM review — then a human approves, retries or discards.

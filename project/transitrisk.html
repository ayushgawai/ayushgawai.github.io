DATA 245 · cost-sensitive forecasting

TransitRisk, delay forecasting

Predicts whether a station-route pair will see elevated delay in the next hour: seven classifiers, probability calibration, conformal prediction and a cost-optimal alert threshold when a miss costs 5× a false alarm.

DATA 245 · ML

TransitRisk

Next-hour delay risk per station-route pair from 38 leakage-audited features. Seven calibrated classifiers with conformal intervals; the alert threshold minimizes expected cost, not error.

  • 0.163 alert threshold
  • 38 features
Code on GitHub
Technical deep dive
  • ~1.2M generated transit events; cleaning and a leakage audit before feature engineering.
  • Naive Bayes, logistic regression, kNN, decision tree, random forest, SVM and XGBoost, all probability-calibrated.
  • Threshold chosen where a missed delay costs 5× a false alarm: 0.163. Conformal prediction, SHAP, weather and stress tests, ablations, what-if analysis.
  • Streamlit dashboard with per-route gauges and a live-feed replay; 15 tests covering features, leakage, conformal coverage and targets.

the design calls

Calibrate, then threshold on cost

Accuracy is the floor; the operating point is a business decision.
